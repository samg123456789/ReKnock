# ReKnock Codex operating rules

The internal product and engineering agent workflow lives in Codex, not in the
ReKnock customer web app. Read `docs/CODEX_OPERATING_MODEL.md` before taking
on product, engineering, reliability, or growth work.

Use Codex goals, plans, queued prompts, steering, review, and explicit approval
for repository changes. Do not recreate Compass, Forge, Signal, or a hosted
Company OS dashboard inside the product unless the user explicitly changes this
architecture.
